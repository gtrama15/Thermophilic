# Thermophilic

Analysis code for residue-pair-resolved amide-I vibrational exciton
coupling in the phosphorylated (1QMP) and unphosphorylated (1DZ3) forms
of the *Geobacillus stearothermophilus* Spo0A receiver domain.

- `physics/` — electrostatic frequency map, TDC coupling, exciton
  Hamiltonian, and 2D-IR response calculation
- `analysis/` — ensemble definition, decomposition, robustness checks,
  and summary tables
- `figures/` — scripts that regenerate the manuscript figures and tables

See the manuscript Methods section for the full description of each step.

## Data availability

Molecular dynamics trajectories and intermediate per-snapshot coupling
data are available from the corresponding author upon reasonable request.
